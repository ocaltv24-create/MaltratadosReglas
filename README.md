# Maltratados RP · Normativas

Sitio oficial de consulta de las reglas de la comunidad.

**Web:** https://ocaltv24-create.github.io/MaltratadosReglas/#generales

## Qué incluye

- Normativas generales, policiales, ilegales, EMS y Discord.
- Reglas escritas organizadas por temas, con avisos importantes.
- Ejemplos de lo correcto e incorrecto.
- Buscador y filtros por categoría, tema, importancia y ejemplos.
- Identidad visual de agua y fuego y efectos animados opcionales.

## Publicación

Web estática, sin instalación ni compilación. Los archivos `index.html`, `style.css`, `app.js` y `reglas.js` deben estar en la raíz, junto con la carpeta `assets/`.

GitHub Pages debe publicar desde la rama `main` y la carpeta `/(root)`. Se conserva el nombre del repositorio y, por tanto, la dirección pública existente. `.nojekyll` permite servir directamente los archivos estáticos.

No contiene archivos PDF. El contenido escrito está en `reglas.js`; los ejemplos orientativos ilustran las reglas sin crear sanciones ni requisitos nuevos.
